# Roadmap: From Core to Demonstrated Production Depth

## Included in this clean-room base
- Local-first CLI, authenticated loopback HTTP API and MCP JSON-RPC surface.
- ComfyUI API and SD WebUI adapters; Klein/Z-Image recipe builders based on prior tested workflows.
- Godot, Blender and RIFE probes; guarded Godot validation/export.
- SQLite runs/events/asset/feedback state.
- Workflow state machine and 24h/72h/14d task planner with DAG cycle checks.
- Optional image inspection/refinement, contact sheets, deterministic atlas packing and animation diagnostics/assembly.
- Bounded creative MCP server over stdio (preflight, animation-sequence and pose-spec validation, Blender inventory/authoring/render review) plus a read-only `ags readiness` report.
- Structured JSON Schema contracts, 87 specialist skills, agent-first production contract, animation execution runbook, research register and known-limitations guide.

## Highest-value next steps based on evidence
1. Improve generation queue job persistence, cancellation, retry and resume.
2. Add a reference-identity review system with accepted/rejected candidate decisions and explicit human ratings.
3. Prototype Blender-to-sprite production against reference-guided frame workflows on a common workload.
4. Keep host-level Freebuff/Claude/MCP integration coverage current as connector versions change.
5. Extend visual-review tooling for animation playback and in-engine asset comparison.
6. Add new game templates only when they include playable loop, art direction, audio, tests and reproducible release.
7. Calibrate jam estimates from real projects/postmortems.

## Explicitly not promised
This roadmap does not guarantee AAA quality, industry dominance, market success, or any business valuation. Those depend on execution, player response, design, rights, team capability and market factors that a repository alone cannot determine.
