# Specialist Skill Library

The authoritative playbooks live in `skills/<skill-id>/SKILL.md`. They use compact frontmatter and standard procedure/acceptance/failure/evidence/handoff sections so compatible agents can retrieve only the skills relevant to the current project.

The library covers discovery, creative thesis, core loop and systems, action, platformers, roguelites, RPG, tactics, deckbuilders, survival/crafting, puzzles, horror, narrative, racing, simulation, Metroidvania, shooters, multiplayer risk, procedural generation, art direction, pixel/painterly/anime/isometric/low-poly/realistic/voxel/graphic styles, characters, environments, props, image prompting, ComfyUI, model benchmarking, refinement, extraction, upscaling, atlases, animation principles/keyframes/cutout/RIFE/Godot/Blender, VFX, lighting, materials, UI, audio, accessibility, level design, game AI, physics, architecture, Python, performance, QA, playtesting, visual review, licensing, security, MCP, release, planning, postmortems, save/load, localization, camera, narrative, content pipelines, agent handoffs, cross-platform export, and evidence standards.

Use `ags skills search <query>` or `ags skills read <skill-id>`. Skill presence means guidance is available; it does not mean every corresponding production capability has been implemented or tested. Use the capability register for that distinction.
