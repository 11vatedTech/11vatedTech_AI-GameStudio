# Freebuff Entry Point

1. Read `AGENTS.md` first; it is canonical.
2. Read `docs/studio/11vatedtech-game-production-canon.md` and the duration-specific jam workflow.
3. Use `ags doctor`, `ags skills search "<current task>"`, `ags capabilities`, and the project's schemas before planning work.
4. Work from the actual project directory; preserve releases and evidence; do not expand architecture without a production blocker.
5. Execute through integration, playtesting and release audit. Return evidence paths and honest open gates.

Freebuff-specific command setup belongs in your host configuration. The repository does not assume a proprietary Freebuff API or call Freebuff as an external service.
