## Agent-first creative execution contract (required)

The AI agent owns routine creative production. Use all relevant installed/available tools to generate, repair, rig, animate, integrate and verify requested visual content. Never ask the operator to create missing art merely because one method failed.

**Do not ship substitutes as finished art:** primitives, bare SVG/canvas/gradient visuals for designed characters/environments/props/creatures; a static image with pulse/scale/rotation labeled animation; unrelated pose images labeled a cycle; interpolation labeled action generation; or placeholders left in final content without explicit approval. Such techniques are acceptable only when they are an intentional part of the agreed art direction or a clearly labeled temporary test fixture.

For each important asset: specify → discover live tools/models → select method → make a small proof → inspect → repair or switch methods → integrate into the real project → verify in the target renderer/engine → record evidence. Routine quality iteration should be agent-executed. Ask the operator only for genuinely subjective direction, required permissions, or explicitly human-only review gates.

**Animation means authored movement.** Define action phases, anticipation, weight transfer, contact, follow-through, recovery, transitions and synchronized gameplay/VFX/audio events. Use reference-conditioned keyframes, layer reconstruction/cutout, rigged 3D/Blender actions, compatible motion capture/retarget, or a justified hybrid. Interpolation is only a refinement after the key poses already form a coherent action. Do not call frame assembly or animated UI motion character animation.

Preflight VRAM/RAM/disk and serialize heavy GPU work. A resource block suspends that job but must not downgrade the acceptance criteria; continue safe CPU-side work and resume when the resource gate clears. Every claim must state its evidence level: detected, connected, workflow-verified, artifact-valid, integrated, runtime-verified, agent-approved, operator-approved or rights-cleared.
